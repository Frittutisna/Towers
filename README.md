# Towers v1.0.0

## Rules
* Connect all Capacity tiles to a **Tower** within 15 cable lengths and minimize build cost/time
* Lay **Small/Large Cables** from **Towers** to **Capacity** tiles, or place **Extra Towers** and connect them using **Tower Cables**
* You can't build on **Mountain** tiles
* Laying cables on **River** tiles costs 40/30 per cable-tile
* Click **Finish** after all **Capacity** tiles are fully served to lock your score (Cost &times; Build Time + Draw Time)
